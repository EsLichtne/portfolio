How I work

Principles I follow when building products

01

Product architecture

I figure out where data comes from, where it is stored, who changes it and how product entities connect. This way, the interface grows from how the product actually works

02

User research

I design based on research into users’ needs, context and mental models. This way, the interface relies on data, not on assumptions about users

03

Design system

I treat the design system as the product’s working infrastructure: I build interfaces with it and extend it where new patterns, states and product tasks appear

04

Design engineering

I build interfaces myself, from components to prototypes, screens and states. This shortens the path from decision to production and keeps the interface consistent from Figma to the user
